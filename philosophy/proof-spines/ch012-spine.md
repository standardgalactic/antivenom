# Spine: ch012 — Combinatorial Histories

**Volume:** II: Causal Explosion
**Part:** III. The Combinatorics of Context
**Status:** spine

## Claim
Combinatorial histories scale as \(n!\), \(q^m\), and even super-exponential graph families, so responsible judgment must prune and compare structured possibilities rather than treat one salient narrative as self-announcing.

## Depends on
- ch011 — an event's visible trigger sits inside a wider causal graph whose relevant neighborhood must be mapped before attribution is warranted.

## Load-bearing steps
1. Because \(n\) relevant events can be temporally arranged in many ways, candidate reconstructions can grow on the order of \(n!\) even before adding uncertainty about values or edges.
2. Because \(m\) variables with \(q\) plausible values generate \(q^m\) joint assignments, the same visible outcome can sit atop an enormous hidden state space.
3. Because uncertainty about directed causal edges adds super-exponentially many possible graph structures, historical multiplicity is built into the problem rather than added by philosophical excess.
4. Because investigators cannot enumerate that whole space, pruning rules are unavoidable; the core epistemic question is which pathway families remain testable after those rules cut the search tree.
