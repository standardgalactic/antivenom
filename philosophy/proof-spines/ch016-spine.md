# Spine: ch016 — Unknown Unknowns

**Volume:** II: Causal Explosion
**Part:** III. The Combinatorics of Context
**Status:** spine

## Claim
When the true explanation satisfies \(H^\ast\notin\mathcal H\), inquiry faces model incompleteness rather than ordinary uncertainty, so institutions need procedures that can surface and test unknown unknowns.

## Depends on
- ch011 — inquiry begins from an observed event whose full causal neighborhood is not self-announcing.
- ch012 — many structured histories remain live behind the same outcome.
- ch013 — disciplined comparison among alternatives is necessary for causal judgment.
- ch014 — rational suspicion must be calibrated to the environment's actual error profile.
- ch015 — some systems disclose relevant structure only through unfolding interaction rather than ex ante compression.

## Load-bearing steps
1. Because ordinary probability presumes a fixed hypothesis space \(\mathcal H\), it cannot by itself represent the case in which the true explanation satisfies \(H^\ast\notin\mathcal H\).
2. Because that mismatch is model incompleteness rather than mere uncertainty, the chapter must distinguish risk, ambiguity, ignorance, and ontology failure instead of collapsing them into one probabilistic bucket.
3. Because institutions often mistake their current \(\mathcal H\) for the limits of reality, they need mechanisms—appeal, reopening, anomaly reporting, adversarial challenge—that let an omitted hypothesis become articulable and testable.
4. Because openness to \(H^\ast\notin\mathcal H\) is not a license for indiscriminate speculation, disciplined paranoia here means preserving channels for model revision while still demanding evidence once a new hypothesis is proposed.

## Objections this chapter must survive
- **Objection:** Once "unknown unknowns" enter the argument, any conjecture can demand equal respect because the decisive factor might always be hidden. **Response:** The chapter limits the point to institutional openness to surprise and model revision, not indiscriminate credence toward arbitrary suspicions.
