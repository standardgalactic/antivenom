## Claim
The non-implication chain \(\operatorname{Record}\centernot\Rightarrow\operatorname{Verify}\centernot\Rightarrow\operatorname{Recognize}\centernot\Rightarrow\operatorname{Authorize}\centernot\Rightarrow\operatorname{Continue}\) is the basic grammar of trustworthy institutional state change.


## Depends on
- **ch046, "Delay, Liberty, and the Protected Interval"** — liberty depends on preserving a protected interval in which accusation can still be tested before irreversible action.

## Load-bearing steps
1. Because Volume IV ends with a protected interval, this chapter specifies the typed operators that can responsibly fill that interval instead of letting appearance jump straight to consequence.
2. \(\operatorname{Record}\) creates persistence only: it stores a trace without yet proving authenticity, accuracy, or proper handling.
3. \(\operatorname{Verify}\) then establishes specified relations between claim and trace, but a verified trace still does not by itself settle what institutional category the object occupies.
4. \(\operatorname{Recognize}\) places the verified object within a category, after which \(\operatorname{Authorize}\) separately licenses action and \(\operatorname{Continue}\) asks whether that license remains active across time.
5. The chapter therefore grounds trustworthy state change in explicit non-implication between these operators, multiplying audit points and preventing any one act from self-certifying the rest.

## Objections this chapter must survive
- **Objection:** In practice the same official or system often performs all four functions, so separating them conceptually adds bureaucracy without adding truth. **Response:** Even when housed in one office, the distinctions create audit points, appeal points, and failure localization that a fused command structure cannot supply.
