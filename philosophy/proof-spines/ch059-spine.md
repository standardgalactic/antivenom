## Claim
Disciplined paranoia begins with a nested attacker-model family \(\mathcal A_0\subset\mathcal A_1\subset\cdots\subset\mathcal A_k\), so institutions state which adversarial capabilities they resist instead of invoking generic security.

## Depends on
- ch058 — custodial institutions preserve records, boundaries, and procedures so that appearances remain available for later judgment, which this chapter carries into conditions where some actors intentionally try to poison those channels.

## Load-bearing steps
1. Introduce the nested adversary family \(\mathcal A_0\subset\mathcal A_1\subset\cdots\subset\mathcal A_k\) so that hostile capability is represented as ordered classes rather than an all-or-nothing label.
2. Specify that movement up the chain adds concrete powers---lying, omission, framing, flooding, intimidation, collusion, impersonation, and procedural exploitation---instead of treating ``adversary'' as a vague menace.
3. Use the model to separate anomalies consistent with error or routine incentive from anomalies that require an actor in some \(\mathcal A_i\), preventing suspicion from leaping straight from surface disturbance to hostile intent.
4. Conclude that institutional design should announce which \(\mathcal A_i\) it can resist and where its guarantees fail, replacing generic security rhetoric with bounded adversary claims.

## Objections this chapter must survive
- Modeling adversaries at the outset invites conspiracism, because humans already over-attribute intention and will start seeing enemies behind ordinary noise.
- Response: the whole point of the typology is to force comparison with accident and routine incentive explanations before hostile agency is inferred.
