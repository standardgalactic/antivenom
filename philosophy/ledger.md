# Ledger — The Power of Paranoia

Single source of truth for where the book stands. Update this whenever
a chapter's status, dependencies, or load-bearing cases change in its
proof-spine file — the ledger is a derived view, not an independent
record, so if it and a spine disagree, the spine is correct and the
ledger needs fixing.

## Status legend
- `outline` — title and part assigned, no spine yet
- `spine` — proof-spine drafted (Claim, steps, dependencies, objections)
- `prose-drafted` — chapter text drafted from the spine
- `reviewed` — a review pass has been applied
- `frozen` — no further changes expected barring a whole-book revision

proof-spine (Claim, load-bearing steps, dependencies, objections) built

progressed to prose-drafted. ch074 and ch086 also carry drafted spines.
