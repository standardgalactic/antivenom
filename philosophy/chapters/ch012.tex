\chapter{Combinatorial Histories}
\label{ch:ch012}

Once causal neighborhoods expand, histories multiply rapidly. If \(n\) potentially relevant events can be ordered in multiple ways, the number of candidate temporal structures may approach
\[
n!.
\]
\ToyModel\ This factorial count is a stylized lower bound on historical multiplicity.
If each of \(m\) variables has \(q\) plausible values, the joint assignment space contains
\[
q^m
\]
\ToyModel\ This product-space count isolates how hidden-state variation outruns any single visible outcome.
possibilities; if directed causal edges are uncertain, the number of admissible graphs grows super-exponentially. This is the combinatorial setting in which legal and political reconstruction actually operates.

The point is not that investigators literally enumerate every candidate history. The point is that every workable inquiry must impose pruning rules on an underlying space that is vastly larger than the official narrative usually admits. Those pruning rules are epistemically decisive, because they determine which truths remain discoverable and which pathways are discarded before they can even be tested.
